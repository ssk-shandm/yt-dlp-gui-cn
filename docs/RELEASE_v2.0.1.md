# v2.0.1 — 更新下载修复版

本次更新修复应用内安装包下载失败的问题，改善 Windows 系统代理和企业证书环境下的更新体验。

## 更新内容

- **修复更新下载失败**：下载器使用 Windows 系统信任的根证书，并支持系统代理；保持 HTTPS 证书校验。
- **优化超时处理**：连接超时为 30 秒、单次读取超时为 60 秒，不限制大安装包的总下载时间。
- **改善错误提示**：更新失败时显示具体原因，并针对证书、连接和超时提供处理建议。

## 下载与安装

在本页 **Assets** 中下载 `yt-dlp.GUI_2.0.1_x64-setup.exe`，运行安装器并按提示完成安装。已有版本也可在“关于”页检查更新。

安装包已包含 yt-dlp、FFmpeg 和 ffprobe，无需单独安装 Python、Node.js 或 Rust。请使用完整安装包，不要只复制主程序 EXE。

## 使用须知

- 仅支持 **Windows x64**。
- 安装包**未签名**，Windows 可能显示 SmartScreen 提示，请确认下载来源并核对 SHA-256。
- 缺少 WebView2 时，安装器可能联网下载运行时；此包不是完全离线安装包。
- 自动更新仅适用于已安装的 NSIS 版本；开发版和便携版不会自动替换程序。
- 请仅下载和处理有权获取的内容，并遵守目标网站条款。
