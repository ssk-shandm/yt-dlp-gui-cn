# 更新日志

## [2.0.0] — 2026-10-06

### 界面优化

- 封面初始与重置状态改为空白占位，支持分析中反馈和加载失败提示。
- 统一侧栏、页面标题、主内容区、卡片间距与响应式布局；移除固定 50% 的示例进度，展示实际任务统计。
- 新增页面切换、导航与按钮悬停、卡片反馈、封面加载动效，并尊重系统“减少动画”偏好。
- 新增“关于”页；最终精简为“项目基本信息”和“设置”两部分，信息仅保留版本号、版权、MIT 许可与项目仓库。
- 移除“本地桌面工具”、侧栏品牌图标/名称/副标题及“开源 · 本地运行”，收紧导航顶部留白。
- 桌面端从 GitHub Releases 检查正式版本，支持“关于”页手动检查和启动时自动检查；更新时下载并启动文件名以 `-setup.exe` 结尾的 NSIS 安装包。活动任务会延后安装，浏览器预览、开发版和便携版不执行自动安装。
- 由根目录“视频下载工具图标设计.png”生成 1024px RGBA PNG，并生成多尺寸 Windows ICO 与 Tauri 图标集，供 EXE 构建使用。
- 关于页使用原生浏览器打开项目链接，权限仅允许三个预设项目 URL。新增 UI 浏览器烟测。

### 新增

- Tauri 2 / Rust Windows 桌面入口与当前用户 NSIS 安装配置。
- 原生目录选择、设置持久化、本次运行任务列表和任务取消。
- 最多 4 个并发任务、解析/下载超时、进程输出与退出清理。
- Rust 单元测试、前端状态/配置测试、真实 WebView2 桌面烟测和打包工具预检。
- 开发、架构、构建、迁移、测试、第三方工具说明文档。

### 变更

- 保留 Vue 前端，将 Python/Eel 通信替换为 Tauri IPC。
- 更新 Vue、Vite、Vue 插件、类型检查和 ESLint 工具链，移除 ANSI-to-HTML 与旧 ESLint 配置依赖；本地 npm audit 报告 0 漏洞。
- 外部 yt-dlp / FFmpeg 作为应用资源分发，不再用 PyInstaller 打包应用层。
- 详细项目文档统一放入 docs；删除过时的 Python/Eel、Docker 使用指南及重复的 UI 改进、PR 和工作总结，按用途整理文档索引。
- 旧 Python/Eel、Docker 和 pnpm lock 移到 legacy/python-eel；当前依赖统一由 npm 管理。
- 终端改为纯文本渲染，并限制内存中日志与结束任务记录数量。

### 修复

- 封面下载误传目录而非视频链接。
- 重试次数的默认值、类型和分支逻辑。
- 解析失败/陈旧响应导致的加载状态和链接标记问题。
- 下载任务缺少统一错误结果和子进程生命周期管理。
- HTTP 封面在 CSP 下的展示；目录和重试设置保存使用补丁队列，避免互相覆盖。

### 本地验证

- Windows x64 NSIS 安装包构建成功，约 110.24 MiB。
- 前端 19 项（含自动更新与多尺寸图标校验）、UI 浏览器烟测、Rust 7 项测试通过；构建、ESLint、Rust 格式与 Clippy 检查通过。
- 真实桌面烟测验证六种下载模式、Vue 解析与封面、中文路径、并发限制、取消和正常退出进程清理。
- 安装/升级/卸载、干净机、外部站点和发行许可尚待验收；完整范围见 TESTING.md。

### 已知限制

- 当前只验证 Windows x64；不提供其他平台安装包。
- 自动更新要求发布者上传文件名以 `-setup.exe` 结尾的 Windows NSIS 安装包；当前仅适用于已安装的 Windows x64 当前用户版本。
- WebView2 缺失时安装器需要网络；安装包尚未配置签名。
- 第三方二进制许可和正式发布验收需要独立审核。

## [1.0.0] — 历史版本

Vue 3 + Python/Eel 实现，使用外部 yt-dlp / FFmpeg 与 PyInstaller。无法从当前源码确定准确发布日期，因此不补造日期。旧实现源码仅保留在 legacy/python-eel/ 供参考，过时的使用文档不再保留。
